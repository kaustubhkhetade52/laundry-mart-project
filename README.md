# laundry-mart-project


This is a basic laundry service website created using HTML5.
It was made as a beginner project to practice the fundamentals of HTML.

## Features

* Laundry services section
* Price list
* Basic booking form
* Contact information
* Laundry-related image

## Technologies Used

* HTML5
